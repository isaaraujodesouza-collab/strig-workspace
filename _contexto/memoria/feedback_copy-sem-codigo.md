Quando a Isa pede pra reformular copy (landing page, post, qualquer texto), a entrega é só texto legível. Nunca gerar ou salvar HTML/código nos arquivos do cliente junto disso, nem quando o texto vai eventualmente virar uma página existente.

**Why:** ela pediu reformulação de copy do LF Buffet, entreguei o HTML da landing page implementado direto. Ela rejeitou duas vezes, inclusive depois de eu ainda deixar uma referência técnica ("entregas/index-reformulado.html") dentro do .md de copy — disse claramente "não quero saber de código isso não é problema meu, não preciso disso nos meus arquivos". Implementação técnica é outra etapa, decidida à parte, não algo que se anexa por conta própria a um pedido de copy.

**How to apply:** se o pedido é sobre copy/texto, entregar só copy/texto, em markdown puro ou resposta direta no chat. Não criar arquivos HTML, não referenciar arquivos técnicos no mesmo documento, mesmo que exista uma página real por trás. Só produzir código/implementação se for pedido explicitamente à parte.
